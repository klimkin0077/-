# wells-mo.ru — Премиум сайт Wells‑MO

Этот репозиторий содержит статический многостраничный сайт для компании Wells‑MO (чистка/копка колодцев, дренаж участка).

Содержимое:
- index.html — главная
- /services/ — страницы услуг
- /gallery/ — галерея
- /contacts/ — контакты и форма
- /assets/ — CSS, логотип, временные заглушки
- CNAME — wells-mo.ru (уже добавлен)

Как развернуть на GitHub Pages:
1. В разделе Settings → Pages выберите ветку `main` и / (root) для ресурса, сохраните.
2. На регистраторе домена добавьте A‑записи для GitHub Pages:
   - 185.199.108.153
   - 185.199.109.153
   - 185.199.110.153
   - 185.199.111.153
3. Убедитесь, что файл `CNAME` содержит `wells-mo.ru` (он уже добавлен).

Форма обратной связи:
- Сейчас форма отправляет данные на Formspree: замените `https://formspree.io/f/your-form-id` в `contacts/index.html` на ваш endpoint Formspree или настройте Netlify Forms.

Замена фотографий:
- Поместите реальные фотографии в `/assets/` и замените `placeholder-*.jpg` соответствующими файлами.
